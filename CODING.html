Algorithms and coding

Thirteen patterns cover most interview problems. For each: how to spot it, a template in Python, and classic problems with the solution shut until you have tried. Start with how to code out loud.

How to code in an interview

  1. Restate the problem in one sentence, and ask about input size, empty input, duplicates and negative numbers.
  2. Say the brute force and its cost before anything clever. It's a correct answer you can improve.
  3. Name the pattern ("this is a sliding window") and the better complexity.
  4. Write it while talking. Clear names over short ones. Syntax matters less than structure.
  5. Run one small example by hand, then the edge cases: empty, one element, all the same.
  6. State time and space at the end, and one way you'd improve it if they asked.

Say it out loud

  • 1 Restate it; ask size, empty, duplicates, negatives.
  • 2 Brute force and its cost, first.
  • 3 Name the pattern and the target cost.
  • 4 Code while talking; clear names.
  • 5 Trace one example, then empty, one, all-same.
  • 6 Time and space; one improvement.

The input tells you the target

  • n ≤ 20: 2n, backtracking · n ≤ 500: n3 · n ≤ 5,000: n2
  • n ≤ 106: n log n or n · huge: log n or math
  • Sorted → binary search, two pointers
  • Contiguous → window; with negatives → prefix sums
  • Top k → heap · fewest steps → BFS
  • Count ways / min cost → DP · every combination → backtracking

Arrays and hashing

Spot: Seen it before? Pairs, duplicates, groups, counts.

Move: dict value → index, Counter, set.

seen = {}
for i, x in enumerate(a):
    if t - x in seen: return [seen[t - x], i]
    seen[x] = i
  • Group anagrams: key = tuple(sorted(w)).
  • Longest run: start only where x - 1 not in set.
  • O(n) time, O(n) space.

Prefix sums

Spot: Subarray sum equals k; range sums; negatives allowed.

Move: Count earlier prefixes equal to run - k.

seen, run, ans = Counter({0: 1}), 0, 0
for x in a:
    run += x
    ans += seen[run - k]
    seen[run] += 1
  • Seed {0: 1}: a run from index 0.
  • Range sum = pre[r + 1] - pre[l].
  • O(n).

Two pointers

Spot: Sorted array; pair or triplet sums; palindromes; in place.

Move: Ends inward; move the side that fixes it.

l, r = 0, len(a) - 1
while l < r:
    s = a[l] + a[r]
    if s == t: return l, r
    if s < t: l += 1
    else: r -= 1
  • 3sum: sort, fix i, two pointers; skip duplicates.
  • O(n) after an O(n log n) sort.

Sliding window

Spot: Longest or shortest contiguous run with a rule.

Move: Grow right; shrink left while invalid.

l = best = 0
for r, c in enumerate(s):
    cnt[c] += 1
    while bad(cnt):
        cnt[s[l]] -= 1; l += 1
    best = max(best, r - l + 1)
  • Works only if shrinking restores validity.
  • Length is r - l + 1. O(n).

Stack

Spot: Brackets; next greater or warmer; undo; expressions.

Move: Pop while the top is answered by the current item.

st = []
for i, x in enumerate(a):
    while st and a[st[-1]] < x:
        j = st.pop(); ans[j] = i - j
    st.append(i)
  • Store indices, not values.
  • Each item pushed and popped once: O(n).

Binary search

Spot: Sorted; rotated; smallest k such that a check passes.

Move: Halve the range; keep one invariant.

lo, hi = 0, len(a) - 1
while lo <= hi:
    mid = (lo + hi) // 2
    if a[mid] == t: return mid
    if a[mid] < t: lo = mid + 1
    else: hi = mid - 1
  • On the answer: lo, hi = min, max; test check(mid).
  • bisect_left(a, x): first index with a[i] ≥ x.
  • Rotated: one half is always sorted. O(log n).

Linked lists

Spot: Reverse, cycle, middle, merge, kth from the end.

Move: Dummy head; prev and cur; slow and fast.

prev, cur = None, head
while cur:
    nxt = cur.next
    cur.next = prev
    prev, cur = cur, nxt
return prev
  • Cycle: fast two steps, slow one; they meet.
  • Kth from end: fast starts k ahead. O(n), O(1).

Trees

Spot: Depth, paths, validate a BST, LCA, level order.

Move: Recurse and return info up; BFS for levels.

def depth(n):
    if not n: return 0
    return 1 + max(depth(n.left), depth(n.right))
  • BST: pass (lo, hi) bounds down; in-order is sorted.
  • Levels: for _ in range(len(q)).
  • O(n) time, O(h) stack.

Graphs: BFS and DFS

Spot: Grids, islands, components, fewest steps.

Move: BFS for fewest steps; mark seen when you push.

q, seen = deque([s]), {s}
while q:
    u = q.popleft()
    for v in g[u]:
        if v not in seen:
            seen.add(v); q.append(v)
  • Grid: four directions and a bounds check.
  • Build g with defaultdict(list). O(V + E).

Graphs: order and weights

Spot: Prerequisites; weighted shortest path; merging groups.

parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
  • Topological (Kahn): queue indegree 0; done < n means a cycle.
  • Dijkstra: heap of (dist, node); skip stale; no negative weights. O(E log V).
  • Union-find: components, redundant edge; union = parent[find(a)] = find(b).

Heaps and top k

Spot: Top k, kth largest, merge k sorted, scheduling.

Move: Min-heap of size k keeps the k largest.

h = []
for x in a:
    heapq.heappush(h, x)
    if len(h) > k: heapq.heappop(h)
return h[0]  # kth largest
  • heapq is min only: push -x for a max-heap.
  • Ties: push (key, i, item). O(n log k).

Intervals

Spot: Overlap, merge, insert, meeting rooms.

Move: Sort by start; compare with the last end.

out = []
for s, e in sorted(iv):
    if out and s <= out[-1][1]:
        out[-1][1] = max(out[-1][1], e)
    else: out.append([s, e])
  • Rooms needed: a heap of end times.
  • O(n log n) for the sort.

Dynamic programming

Spot: Count ways, min or max cost, can you; choices overlap.

Move: State in words, recurrence, base, order.

dp = [0] + [inf] * amt
for x in range(1, amt + 1):
    for c in coins:
        if c <= x:
            dp[x] = min(dp[x], dp[x - c] + 1)
  • Start top-down with @cache, then a table.
  • Two strings: dp[i][j]. Only the last row needed: O(n) space.
  • Know: climb, rob, coin change, LIS, LCS, knapsack.

Backtracking

Spot: Every subset, permutation or combination; n small.

Move: Choose, recurse, undo.

def go(i, path):
    if i == len(a):
        out.append(path[:]); return
    go(i + 1, path)            # skip
    path.append(a[i])          # take
    go(i + 1, path)
    path.pop()                 # undo
  • Copy the path when you save it.
  • Sort and skip duplicates; prune early.
  • O(2n) subsets, O(n!) permutations.

Edge cases to say

  • Empty input; one element; all the same.
  • Negatives and zero; duplicates.
  • Already sorted, or reversed.
  • Off by one: r - l + 1, lo ≤ hi.
  • Deep recursion past 1,000: go iterative.
  • Strings: case, spaces, unicode.

Python traps

  • [[0] * m] * n shares rows: use a comprehension.
  • def f(x=[]) shares the list across calls.
  • list.pop(0) is O(n): use deque.
  • s += c in a loop is O(n2): use join.
  • -7 // 2 is -4: floor division.
  • Don't mutate a list while looping over it.

AI-flavoured coding

Spot: Top k by cosine, retries, parsing model output, rate limits.

q = q / np.linalg.norm(q)
M = M / np.linalg.norm(M, axis=1, keepdims=True)
top = np.argsort(-(M @ q))[:k]
  • Retry: sleep base × 2i plus jitter; cap; retry only retryable errors.
  • Model JSON: strip fences, json.loads in try, validate, None on failure.
  • Token bucket: refill elapsed × rate, capped. LRU: OrderedDict, move_to_end.
